  주식종류가 우선주가 아닌 **비보통주(기타 종류주·신주인수권증권 등)** 다. 유니버스는 보통주만 대상이므로 함께 제외하는 것이 맞다 → 규칙 유지.

  → 이름 규칙을 **강한 접미사만**(`N우`, `우B`, `우C`, `우(전환)`, `우(신형)`)으로 좁혔다. 단순 '…우' 우선주는 코드 규칙이 전부 잡는다.
